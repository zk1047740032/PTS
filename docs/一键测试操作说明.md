## 一键测试操作说明
### 一、准备工作

- **1-开机**：打开所有仪器，打开光开关，调至通道1（默认）；

- **2-确认连接**：电脑与种子、功率计以及交换机连接正常，各仪器与交换机连接正常；

- **3-记录种子参数**：点击右上角的「种子参数」，打开弹窗，选择种子串口，查询并记录种子系统信息；
  ![种子参数按钮](help_images\种子参数按钮.png)

  ![种子参数](help_images\种子参数.png)

    此步骤可记录测试报告所需的「工作电流」「光栅温度」「波长调谐范围」等信息。
  ![报告1](help_images\报告1.png)

### 二、开始测试

- **4-手动调整波长**：打开对应波长计软件，调整出光至 PZT 调制所需波长，点击波长计软件「Start」，波长计软件会自动弹出绘图窗口；

- **5-启动一键测试**：回到测试软件，点击「全选」勾选所有测试项，然后点击「一键测试」开始一键测试流程；
  ![一键测试](help_images\一键测试.png)

### 三、测试流程

- **6-一键测试流程**：光路 AB 并发执行，光路 B 内按通道 1、2、3、4 顺序执行，会自动调整光开关至对应通道；同一通道内并发执行；程序正常执行完毕或异常终止时，弹窗会自动关闭；

  - **光路 B**：功率 — 记录功率计读数，根据光路，为种子实际功率的 3%；

  - **光路 A**：

    - **通道 1 — PZT 调制**：记录波长计软件初始界面的截图，各参数下的绘图窗口截图，以及「0.1Hz / 10Vpp / 5Vdc」参数下的「快速频率调谐范围」数据；根据要求，选用「0.1Hz / 10Vpp / 5Vdc」参数下的截图放入测试报告；
      ![PZT调制](help_images\PZT调制.png)

    - **通道 2 — 时域**：记录 100Hz 与 300Hz 下的截图以及对应峰峰值用于弹窗显示。无用于放入测试报告的数据；
      ![时域](help_images\时域.png)

    - **通道 3 — Rin / 种子光(一键测试) / 线宽 / 信噪比 / 单频**：

        - Rin：记录画 Rin 曲线图以及 RMS 积分值，都放入测试报告；
        ![Rin](help_images\Rin.png)

        - 种子光(一键测试)：通道3有光，调用测Rin程序测种子光函数，Rin结束后调用；无用于放入测试报告的数据；

        - 线宽：记录各频率下仪器截图以及 Ndbdown 值；根据要求，选用 1MHz 时的数据放入测试报告；
        ![线宽](help_images\线宽.png)

        - 信噪比：记录仪器截图及 SNR 值，都放入测试报告；
        ![信噪比](help_images\信噪比.png)

        - 单频：扫出单频时记录仪器截图，测试结果弹窗显示有无单频即可，无用于放入测试报告的数据；
        ![单频](help_images\单频.png)

    - **通道 4 — 相噪 / 底噪(一键测试)**：暂时不用；

        - 相噪：暂时不用；

        - 底噪：通道3无光，调用测Rin程序测底噪函数；无用于放入测试报告的数据；

### 四、测试结束

- **7-测试结束**：显示测试结果弹窗，显示各项测试关键数据，并手动填写激光器型号、编号、序列号等基本信息；关闭测试结果弹窗后，在下一次测试开始前，可以再次点击打开；

- **8-生成报告**：点击测试结果弹窗左下角的「生成报告」可自动生成报告，双击主窗口界面日志区更新的条目，可直接打开查看；
  ![测试结果](help_images\测试结果.png)

### 五、其它设置

- **配置参数**：在「配置参数」界面，可配置仪器地址、各测试项的参数等，可保存记忆；
    ![配置参数](help_images\配置参数.png)

- **网络配置**：可检测各仪器通信状态，若显示「不可达」，说明对应仪器 IP 地址发生变化，在仪器上修改为对应地址即可；
    ![网络配置](help_images\网络配置.png)
