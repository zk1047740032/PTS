### 1. PC 端创建专用账号（必须）

以管理员身份打开 CMD：

```bat
net user pts 1234 /add
```

给这个账号文件夹权限：

```bat
icacls "C:\PTS\zhongzi" /grant pts:F /T
```

### 2. 仪器端保存凭据（必须）

在仪器的 Windows 上，管理员 CMD 执行：

```bat
cmdkey /add:192.168.7.7 /user:pts /pass:1234
```

或者在控制面板 → 凭据管理器 → Windows 凭据里手动添加。

### 3. 仪器端确认网络类型（必须）

在仪器 Windows 上确认连接 PC 的网卡是专用网络（不是公用）：

```powershell
powershell -Command "Get-NetConnectionProfile | Set-NetConnectionProfile -NetworkCategory Private"
```

### 4. 验证

在仪器上打开文件资源管理器，地址栏输入：
\192.168.7.7\PTS
能打开看到文件夹内容就说明通了，后续 MMEM:COPY 就能正常工作。
