# PTS - 频准测试系统介绍文档

## 一、系统概述

### 1.1 系统简介

**PTS (Precision Test System)** 是一个专业的激光器精密测试系统，用于种子源和器件类产品的自动化测试。该系统通过集成多种测试仪器（频谱分析仪、光谱分析仪、示波器、信号发生器等），实现对激光器关键指标的自动化测量、数据采集和结果分析。

### 1.2 应用领域

本系统主要服务于以下产品的测试需求：
- **种子源产品**：单频激光器、宽谱激光器等
- **器件类产品**：温度调谐器件、功率测试器件等

### 1.3 核心价值

- **一体化平台**：集成所有测试模块到统一界面，支持一键测试
- **自动化测试**：减少人工干预，提高测试效率和数据一致性
- **并发执行**：支持多个测试模块同时运行，充分利用多核CPU
- **数据可视化**：实时显示测试曲线和数据分析结果
- **可扩展性**：模块化设计，便于新增测试项目

### 2.2 多进程架构设计

系统采用 **多进程架构** 解决并发执行问题：

| 特性 | 说明 |
|------|------|
| 进程隔离 | 每个测试模块运行在独立进程中，避免资源冲突 |
| 稳定性 | 一个模块崩溃不影响其他模块和主程序 |
| 多核利用 | 每个进程可使用独立CPU核心 |
| 通信机制 | 使用 `multiprocessing.Queue` 进行进程间消息传递 |

#### 2.2.1 进程间通信

```python
# 主进程
msg_queue = multiprocessing.Queue()  # 消息队列
cmd_queues = {}                     # 各进程命令队列

# 子进程监听命令
def check_command_queue():
    while not cmd_queue.empty():
        cmd = cmd_queue.get_nowait()
        if cmd == "START":
            trigger_test()
```

## 三、主要功能模块

### 3.1 测试模块分类

| 时域测试 | TimeDomain.py | 测量时域特性，适配RIGOL示波器 | start_test() |

| CT-线宽 | CT_L.py | 温度/电流步进下的线宽特性测试 | start_group1() |

### 3.2 核心功能详解

#### 3.2.1 Rin 测试模块

**功能**：测量激光器的相对强度噪声 (Relative Intensity Noise)

**支持的仪器**：
- 罗德与施瓦茨 FSV3004 频谱分析仪
- 中电司仪 4051 频谱分析仪

**测量流程**：
1. 连接仪器并配置参数
2. 测量底噪 (6个频段)
3. 测量种子光信号
4. 自动计算并显示驰誉振荡峰

**输出**：
- 数据文件：Rin_1.DAT ~ Rin_6.DAT
- 图片文件：频谱曲线截图
- 分析结果：RIN功率谱

#### 3.2.2 线宽测试模块

**功能**：测量激光器的线宽特性

**支持的仪器**：
- FSV3004 频谱分析仪
- 信号发生器 (4051)

**测试参数**：
- 中心频率：可调 (默认 80MHz)
- RBW：100Hz
- Span：100KHz ~ 2MHz

**特殊功能**：
- 50km 线宽支持手动定位峰值
- 多种 Span 下保存截图

#### 3.2.3 CT_W 波长测试模块

**功能**：温度步进下的波长调谐特性测试

**支持的仪器**：
- YOKOGAWA 光谱分析仪
- 激光器上位机 (Preci-Seed.exe)

**测试流程**：
1. 第一组：温度步进扫描 (t_start → t_stop)
2. 第二组：电流步进扫描 (group2_start_mA → group2_stop_mA)
3. 支持自动循环

**输出**：
- 每次步进的曲线数据 (.csv)
- 曲线截图 (.png)
- 汇总文件 (Test1_summary, Test2_summary)

#### 3.2.4 单频测试模块

**功能**：单频激光器的异常峰检测

**扫描策略**：
- 温度循环：[温度下限, 温度上限]，温度步长
- 电流循环：[电流下限, 电流上限]，电流步长
- 细扫：指定电流下进行精细扫描

**统计功能**：
- 电流循环次数
- 温度循环次数
- 扫频次数
- 检测出峰次数

## 八、故障排查

### 8.1 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 无法连接仪器 | IP 不可达 | 检查 ping 连通性、VISA 安装、仪器远程控制模式 |
| 二进制读取失败 | 仪器固件兼容性 | 程序会自动回退到 ASCII 读取 |
| GUI 无响应 | 长时间测量或阻塞查询 | 尝试停止后重新连接 |
| 窗口打开失败 | 模块导入错误 | 检查 Python 环境和依赖包 |
| 进程崩溃 | 内存不足或资源冲突 | 减少并发测试项数量 |

### 8.2 调试技巧

1. **查看日志**：右侧日志区域显示详细运行信息
2. **检查进程**：通过任务管理器查看进程状态
3. **单独运行**：在 test 目录下单独运行各测试模块进行调试
4. **修改配置**：在 integration_config.json 中调整仪器 IP 和参数

## 十、开发规范

### 10.1 代码风格

- 使用 UTF-8 编码
- 函数和类名采用驼峰命名法 (CamelCase)
- 变量名采用下划线命名法 (snake_case)
- 添加必要的注释和文档字符串

### 10.2 模块开发

新模块需遵循以下规范：

```python
# 文件结构
class ModuleGUI:
    def __init__(self, parent):
        # 初始化 GUI
        self.setup_ui()
        self.setup_instruments()

    def setup_ui(self):
        # 构建界面
        pass

    def start_test(self):
        # 测试启动方法（名称需在 MODULE_MAP 中配置）
        pass

    def log(self, msg, level="info"):
        # 日志记录
        pass
```

### 10.3 配置管理

新模块需在 `integration_config.json` 中添加配置：

```json
{
    "模块名称": {
        "参数1": "值1",
        "参数2": "值2",
        ...
    }
}
```

### 10.4 注册新模块

在 `main_platform.py` 中注册新模块：

```python
# 1. 添加模块映射
MODULE_MAP = {
    "新模块名称": {"start_method": "start_test", "group": "zhongzi/qijian"},
    ...
}

# 2. 添加导入逻辑
if module_name == "新模块名称":
    from zhongzi.新模块文件 import 新模块GUI as gui_class

# 3. 添加到分组
MODULE_GROUPS = {
    "种子": {"通道1": [..., "新模块名称"], ...},
    ...
}
```
